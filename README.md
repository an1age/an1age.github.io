# Игротека

Сайт с онлайн-играми для компании. Играют с телефона, без регистрации: каждый со своего устройства по ссылке-приглашению или все с одного телефона.

- Сайт: https://an1age.github.io/
- Репозиторий: https://github.com/an1age/an1age.github.io (публичный)
- Старый адрес https://an1age.github.io/poymay-volnu/ переадресует на `/volna/` (репозиторий `an1age/poymay-volnu`, один файл `index.html`).

## Структура

```
index.html            главная: список игр карточками
assets/site.css       общие стили: цвета (светлая и тёмная тема), шрифты, шапка, кнопки, поля, панели, фишки, тосты
assets/firebase.js    конфиг Firebase и SiteFirebase.connect() — подключение и анонимный вход
volna/index.html      «Поймай волну»: разметка
volna/volna.css       стили игры (шкала, раунд, лобби, итоги)
volna/volna.js        вся логика игры и 126 шкал
hues/index.html       «Оттенки» (по мотивам Hues and Cues): разметка
hues/hues.css         стили игры (палитра, фишки, карточка ведущего, итоги)
hues/hues.js          вся логика игры
dev/mockfb.js         имитация Firebase для проверки без сети
dev/test_volna.py     проверка «Поймай волну» на нескольких игроках
dev/test_hues.py      проверка «Оттенков» на нескольких игроках
```

Сборки нет: это обычные статические файлы.

## Как выкладывать

GitHub Pages публикует ветку `main`, папку `/ (root)`. Чтобы обновить сайт: в репозитории **Add file → Upload files**, перетащить изменённые файлы или папки (пути сохраняются), **Commit changes**. Через 1–2 минуты изменения на сайте; у игроков достаточно обновить страницу.

## Firebase

- Проект `poymay-volnu`, бесплатный тариф Spark. Один проект на все игры.
- **Realtime Database** (регион europe-west1) и **анонимный вход** (Authentication → Анонимный).
- Firestore не использовать: его лимит — 50 тыс. чтений и 20 тыс. записей в день, живая стрелка съест его за несколько партий. Realtime Database платит только за трафик (10 ГБ в месяц, 100 одновременных подключений).
- Конфиг лежит в `assets/firebase.js`. Он не секретный, данные защищают правила.

Текущие правила (Realtime Database → Rules):

```json
{
  "rules": {
    "lobby": {
      ".read": "auth != null",
      ".indexOn": ["updatedAt"],
      "$code": { ".write": "auth != null" }
    },
    "rooms": {
      "$code": {
        ".read": "auth != null",
        "game":   { ".write": "auth != null" },
        "needle": { ".write": "auth != null" },
        "players": {
          "$uid": { ".write": "auth != null && auth.uid === $uid" }
        }
      }
    },
    "secrets": {
      "$uid": {
        ".read":  "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    },
    "hues": {
      "lobby": {
        ".read": "auth != null",
        ".indexOn": ["updatedAt"],
        "$code": { ".write": "auth != null" }
      },
      "rooms": {
        "$code": {
          ".read": "auth != null",
          "game": { ".write": "auth != null" },
          "players": {
            "$uid": { ".write": "auth != null && auth.uid === $uid" }
          }
        }
      },
      "secrets": {
        "$uid": {
          ".read":  "auth != null && auth.uid === $uid",
          ".write": "auth != null && auth.uid === $uid"
        }
      }
    }
  }
}
```

Данные «Поймай волну» лежат в корне базы (так сложилось):

- `lobby/<код>`: `{code, hostNick, status, updatedAt, online: {<uid>: true}}` — список открытых комнат. `online` снимается сам при закрытии вкладки (onDisconnect); на главной игры видны только комнаты, где кто-то в сети. Последний вышедший удаляет комнату целиком.
- `rooms/<код>/game` — состояние партии: `mode` (coop | teams | solo), `rounds`, `goal`, `status` (lobby | play | over), `gid` (id партии), `host` (uid админа), `teams {<uid>: 0|1}`, `score {coop, t:[a,b], p:{<uid>: n}}`, `turns`, `used`, `history[]`, `round {...}`.
- `rooms/<код>/players/<uid>`: `{name, joinedAt, online}` — каждый пишет только свою запись.
- `rooms/<код>/needle`: `{n, v, by}` — живое положение общей стрелки, пока её тянут. В «Сам за себя» здесь же `s/<uid>: {n, v}` — стрелка каждого игрока, пока он думает (показывается только экстрасенсу).
- `secrets/<uid>/<код>`: `{key, target}` — цель экстрасенса, читает только он сам.

Данные «Оттенков» лежат под `hues/` и устроены так же:

- `hues/lobby/<код>`: `{code, hostNick, status, updatedAt, online: {<uid>: true}}`.
- `hues/rooms/<код>/game`: `laps` (сколько раз каждый ведёт), `rounds` (= laps × игроков на старте), `status`, `gid`, `host`, `score {<uid>: n}`, `history[]`, `round {n, giver, phase, clue1, clue2, g1 {<uid>: клетка}, g2 {...}, force, ready, target, results, giverPts}`.
- `hues/rooms/<код>/players/<uid>`: `{name, joinedAt, online}`.
- `hues/secrets/<uid>/<код>`: `{key, target}` — цвет ведущего, читает только он сам.

## Как добавить новую игру

1. Папка `/<id>/` с `index.html`, `<id>.css`, `<id>.js` (латиницей, коротко).
2. В `index.html` подключить шрифты Google Fonts (как в `volna/index.html`), `../assets/site.css`, три скрипта Firebase compat 10.12.2 (app, auth, database), `../assets/firebase.js`, затем свой скрипт. Подключение: `const { db, uid } = await SiteFirebase.connect()`.
3. Данные игры держать под своим префиксом: `<id>/lobby`, `<id>/rooms`, `<id>/secrets`. Добавить для него правила в Realtime Database → Rules, не трогая правила «Волны».
4. Добавить карточку игры на главную (`index.html`, блок `.games`) и ссылку «← Все игры» (`../`) на главном экране игры.
5. Цвета брать только из токенов `assets/site.css`, чтобы работали обе темы.

## Дизайн

- Интерфейс на русском. Основной экран — телефон: одна колонка до 580px, отступы по краям от 16px, крупные кнопки-клавиши.
- Шрифты: Unbounded — заголовки, Golos Text — текст, JetBrains Mono — цифры и метки.
- Палитра в `assets/site.css`: тёмно-зелёная шкала «радиоприёмника», красно-оранжевый акцент, тёплые зоны очков. Светлая и тёмная темы по системной настройке.

## Поймай волну: правила и логика

Экстрасенс крутит диск: под шторкой — цель с зонами 4 (±2,5), 3 (±7,5), 2 (±12,5) по шкале 0–100. Он выбирает одну из двух шкал или задаёт свою (две крайности) и даёт подсказку. Остальные ставят стрелку.

Режимы онлайн:
- **Вместе** — общая стрелка, все двигают её вживую; фиксируется, когда все отгадывающие нажали «Согласен» (любой сдвиг сбрасывает согласия). Очки общие, в конце звание по доле от максимума.
- **Команды** — команды ходят по очереди, игра до `goal` очков (админ выбирает 3–30, по умолчанию 10). После фиксации соперники голосуют «левее/правее»; сторона засчитывается, когда все выбрали одно. Угадали — +1 соперникам, если отгадывающие не попали в 4. Отстающая команда после «4» ходит ещё раз.
- **Сам за себя** — у каждого своя скрытая стрелка («Готово»). После ответа всех на шкале появляются все стрелки цветами игроков. Пока игроки думают, экстрасенс видит их стрелки вживую (бледная — ещё двигает, яркая — ответ принят); остальные видят чужие стрелки только после шторки. Каждый получает очки за свою стрелку, экстрасенс — +1 за каждого, кто попал в зону. Админ может «Не ждать остальных».

Общие правила раунда:
- Админ — создатель комнаты (`game.host`); если он ушёл — тот, кто зашёл раньше всех. Только админ меняет режим, число раундов (счётчик 1–30), меняет очки до победы (счётчик 3–30), перемешивает команды, начинает игру и новую партию.
- Пропустить раунд могут только экстрасенс и админ.
- Шторку открывает устройство экстрасенса (только у него есть цель) через 1 секунду после того, как условие выполнено.
- Следующий раунд — когда все в сети нажали «Готов»; смена раунда идёт транзакцией, чтобы сработать один раз.
- Голосование и готовность учитывают только игроков в сети.
- Ключ раунда `rKey` = комната + `gid` партии + номер раунда: новая партия в той же комнате не подхватит старую цель.

На одном телефоне — режимы «Вместе» и «Команды», телефон передают по кругу; состояние хранится в localStorage.

## Оттенки: правила и логика

Палитра 24 × 14 (336 цветов): по горизонтали тон по кругу, по вертикали от пастельных к тёмным. Клетка — номер `строка × 24 + столбец`, подпись вида `F8` (строки A–N, столбцы 1–24). Каждый играет сам за себя, только онлайн.

Фазы раунда (`round.phase`):
- `think` — ведущий берёт карточку из 4 цветов (подальше друг от друга и от прошлых целей), выбирает один и даёт подсказку в одно слово. Основные цвета («красный», «синий»…) называть нельзя — проверка по основам слов.
- `guess1` — каждый тайно ставит фишку (`g1`). Пока не ответили все в сети, чужих фишек не видно.
- `clue2` — устройство ведущего открывает первые фишки всем; ведущий даёт вторую подсказку, до двух слов.
- `guess2` — каждый ставит вторую фишку (`g2`); на клетку с фишкой первого круга ставить нельзя.
- `result` — устройство ведущего считает очки через 0,7 с: каждая фишка — 3 за точный цвет, 2 в рамке 3×3, 1 в кольце 5×5; ведущему +1 за каждую фишку в рамке 3×3. Дальше «Готов», переход раунда транзакцией, как в «Волне».

Ведущий меняется по кругу в порядке входа, игроки не в сети пропускаются. Админ меняет число кругов (1–4), начинает игру, может «Не ждать остальных» и пропустить раунд (ещё пропустить может ведущий).

## Проверка

`dev/test_volna.py` открывает игру в нескольких вкладках и подменяет Firebase имитацией `dev/mockfb.js`. Проверяет: права админа, свою шкалу, голосование и сброс согласий, автошторку, готовность и переход раунда, исчезновение пустых комнат, «Сам за себя» на троих (в том числе стрелки игроков у экстрасенса), «Команды» на четверых (в том числе очки до победы).

```
pip install playwright && playwright install chromium
python3 dev/test_volna.py
```

В конце печатается `FAILS: []`, если всё прошло. «Оттенки» проверяет `python3 dev/test_hues.py`: права админа, запретные подсказки, скрытые фишки, второй круг, занятые клетки, очки за точное попадание, «Не ждать остальных», пропуск, итоги, пустые комнаты.
